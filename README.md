# Warehouse simulation world for Gazero Harmonic + ROS2 Jazzy
This branch contains an updated version of the original warehouse simulation made by [Wang Han](http://wanghan.pro), Nanyang Technological University, Singapore. This simulation environment of a warehouse is compatible with **Gazebo Harmonic** + **ROS2 Jazzy.

Since I needed only the simulation environment (the Gazero world), I clean up the repository to remove the files related with the Pioneer, SLAM and navigation algorithms.

**Note:** I can't make the "actors" to work, but I kept an world file named `warehouse_with_actors.sdf` with my last tentative.
